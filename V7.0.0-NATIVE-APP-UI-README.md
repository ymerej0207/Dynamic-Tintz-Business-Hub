# Dynamic Tintz OS v7.0.0 — Native App Interface

This release intentionally changes the PRESENTATION LAYER only.

Business logic retained from v6.9.0:
- Quotes / pricing
- Angi + organic leads
- Square draft creation
- iCloud / Google calendar integration
- Operations
- Roll Optimizer
- Inventory forecasting and deductions
- Scrap-first optimizer
- Responses
- Team / time
- Account / permissions
- Historical inventory
- All existing database / Edge Function behavior

## Interface changes

Owner bottom navigation is now:
Home | Quotes | Schedule | Inventory | More

Schedule opens the existing Operations Board.
More opens a mobile bottom sheet containing:
Leads, Follow-Ups, Roll Optimizer, Responses, Team, Account.

No view was removed. No underlying loader or workflow was replaced.

The shell, cards, controls, navigation, inventory, and modals were restyled to match the
approved dark teal native-app mockup.

## Scrap usability change (requested functional exception)

Scrap checkboxes are now selection checkboxes instead of immediately consuming a piece.

Workflow:
1. Expand the desired film / size.
2. Check as many physical scrap pieces as needed.
3. Tap `Mark X Used`.
4. Confirm once.
5. All selected scraps are updated in one database call and the inventory refreshes once.

This eliminates the previous one-piece-at-a-time reload behavior.

## Install

Replace frontend files:
- app.js
- index.html
- styles.css
- service-worker.js

No SQL migration.
No new Edge Function deployment is required for v7.0.0.

The v6.9.0 create-square-draft Edge Function remains included in this package unchanged
for source-control completeness; do not redeploy it solely for this UI release.
