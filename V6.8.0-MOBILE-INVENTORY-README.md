# Dynamic Tintz OS v6.8.0 — Mobile Inventory Accordion

Designed specifically to reduce scrolling on the Inventory page.

## Scrap Cutoffs

Identical cutoffs now collapse into ONE size row with a quantity:

34" x 40"   QTY 4
4 available
4.72 sq ft each

Tap the 34x40 row and it expands to the four physical pieces. Each physical piece
still has its own Used checkbox, Reserved status, Release Reservation button, and
delete button.

Scraps remain grouped:
Film Type -> Beginning Measurement -> Second Measurement -> Individual Pieces

## Whole Inventory Page

Major sections are now collapsible:
- Film Inventory
- Rolls On Hand
- Add Full or Partial Roll
- Scrap Cutoff Inventory
- Historical Inventory Reconciliation
- Add Film Type

Film Inventory is open by default because it is the most important section.

Each FILM inside Film Inventory is also collapsed by default. The closed line shows:
- film/shade
- projected available square feet
- number of active rolls
- IN STOCK / ORDER SOON

Expand a film only when you need physical on-hand, reserved amount, reorder level,
or inventory controls.

Each physical roll is also collapsible. Its closed line shows film, roll name,
square feet remaining, and linear feet. Expand it for Pull Film / Set Remaining /
Remove.
