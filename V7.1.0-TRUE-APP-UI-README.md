# Dynamic Tintz OS v7.1.0 — TRUE Approved App UI

This is the corrective interface build matching the approved dark teal mobile app concept.

Unlike v7.0.0, this release does not simply restyle the old website-like cards. It
reconstructs the major presentation components while retaining their existing IDs,
handlers, Supabase calls, integrations, calculations, and workflows.

VISIBLE CHANGES:
- Dashboard rebuilt as an app dashboard.
- Three compact KPI cards.
- Today's schedule rendered as native-style appointment rows with time tiles/status pills.
- Recent Quotes rendered directly on Home.
- Inventory Snapshot uses REAL circular availability rings.
- Circular percentage = projected available / physical on-hand.
- Main Inventory film rows also have real data-driven circular availability rings.
- Quotes is now list-first like the approved mockup; Quote Builder is expandable.
- Schedule/Operations jobs use time tiles and app-style appointment cards.
- Existing 5-tab native bottom nav retained.
- More sheet retained.
- Scrap multi-select / bulk Mark Used retained.

FUNCTIONALITY NOT CHANGED:
- Pricing matrices and quote calculations
- Quote saving / customer records
- Angi / organic leads
- Square production draft integration
- iCloud / Google sync
- Calendar status rules
- Operations status workflows
- Roll optimizer
- Scrap-first optimizer
- Inventory deductions, forecasts and manual pulls
- Responses
- Team/time
- Account permissions

No SQL migration.
No Edge Function deployment required for THIS v7.1.0 UI correction.
The previously deployed v6.9.0 create-square-draft function remains the correct Square function.
