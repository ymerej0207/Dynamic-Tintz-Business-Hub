# Dynamic Tintz OS v6.6.0 — Manual Film Pull

Adds a Pull Film button to every physical roll.

Use it when you physically pull/pre-cut film before the job:
- enter square feet
- optionally link the scheduled job
- add a note
- inventory is deducted immediately

If linked to a job, the forecast automatically reduces that job's remaining reservation,
and job completion deducts only the balance that was NOT already pre-cut. This prevents
double-deduction.

Set Remaining remains an inventory correction/audit tool. Pull Film is the normal manual
consumption workflow.

Install:
1. Run MANUAL-FILM-PULL-MIGRATION.sql in Supabase SQL Editor.
2. Replace app.js, index.html, styles.css, service-worker.js.
3. Hard refresh/reopen the PWA.

No Edge Function deployment required.
