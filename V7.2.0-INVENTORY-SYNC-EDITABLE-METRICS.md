# Dynamic Tintz OS v7.2.0 — Inventory Sync + Editable Metrics

Fixes the visual/source mismatch between Film Inventory and Rolls On Hand.

ROLLS ON HAND
- Main Rolls On Hand now shows only rolls with remaining film.
- Rolls are grouped by film type.
- Each film group displays the same active-roll count and physical square footage source
  used by Film Inventory.
- Zero-balance rolls are moved into a collapsed Empty / Used-Up Rolls section and do not
  appear as active stock.

This addresses situations where Film Inventory could say 1 active 25% Ceramic roll while
Rolls On Hand still visibly showed older zero-balance 25% rolls.

EDITABLE METRICS
Every inventory metric card is now clickable:
- Physical On Hand -> edit the actual sq ft remaining on each physical roll.
- Scheduled / Reserved -> edit active job reservation sq ft.
- Projected Available -> opens the editor and shows exactly how Physical - Reserved creates it.
- Reorder Level -> edit the Order Soon threshold.

HOME INVENTORY
Tapping a film card/ring on Home now opens that film's metric editor directly rather than
only navigating to Inventory.

DATA INTEGRITY
Projected Available remains calculated instead of storing an independent override. This
prevents Film Inventory, Rolls On Hand, and job reservations from drifting apart. The two
source values that create it are directly editable.

Physical corrections still write inventory adjustment history.
Reservation edits update the active job material plan itself.

No SQL migration.
No Edge Function deployment.
